# Mobile to web SSO with PingOne Identity Cloud

## Introduction

This repository contains sample artefacts for demonstrating how to enable single signon between a mobile app and a webview launched from the app. Refer to the [associated blog](https://medium.com/@christian.brindley/wwwhoosh-creating-a-mobile-launchpad-for-your-web-apps-using-ping-advanced-identity-cloud-79a7faa095ed) for more background.
